# pico sync

This project is a attempt to build a FM synth in zig using the rapberry PI pico 2W and [microzig](https://microzig.tech/docs/getting-started/).

For now, the development target is the [PicoCalc](https://www.clockworkpi.com/picocalc) with a Pico 2W module installed.

## Tools

This project uses [mise](https://mise.jdx.dev) to handle tool dependencies and build automation.
